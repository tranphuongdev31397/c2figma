HTML → Figma Visual Importer
← Về tool

Tool đọc file HTML standalone và tạo một bộ khung visual editable trong Figma. Nội dung HTML được phân tích ngay trên máy của bạn; bản web không upload file lên server.

Cách dùng nhanh trên website

1. Chuẩn bị file

Dùng file .html hoặc .htm standalone có thể mở được trong trình duyệt.

2. Chọn file

Kéo-thả file vào vùng nhập hoặc bấm vùng đó để chọn file từ máy.

3. Tải plugin theo HTML

Nếu chưa cài plugin Figma, bấm Tải plugin theo HTML (.zip), giải nén và import manifest.json trong Figma Desktop. Đây là cách fallback; mỗi HTML sẽ tạo một ZIP riêng.

Cách dùng khuyến nghị: cài plugin một lần

1. Tải plugin

Quay lại trang chính và bấm Cài plugin Figma.

2. Import vào Figma Desktop

Giải nén file tải về, mở Figma Desktop, vào Plugins → Development → Import plugin from manifest…, rồi chọn manifest.json.

3. Render HTML trực tiếp

Mở plugin trong Figma, chọn HTML và bấm Tạo design trong Figma. Các layer editable sẽ được tạo trực tiếp trong file hiện tại.

Lưu ý: chỉ cần cài plugin một lần. Những lần sau không cần tải ZIP cho từng HTML.

Tool tạo được gì?

  • Frame màn hình 1440×900.
  • Sidebar, header và vùng nội dung editable.
  • Text từ title, heading và label.
  • Một số CSS custom properties, button và badge/status.

Giới hạn hiện tại

  • Không chuyển toàn bộ DOM/CSS thành bản pixel-perfect.
  • Không mang logic React, API hoặc dữ liệu động vào Figma.
  • Layout đặc biệt có thể cần bổ sung mapping trong source importer.

Khi có lỗi

  • Kiểm tra file có đuôi .html hoặc .htm.
  • Dùng Figma Desktop, không dùng Figma trên trình duyệt để import plugin development.
  • Nếu plugin cũ không cập nhật, import lại manifest sau khi tải bản ZIP mới.
